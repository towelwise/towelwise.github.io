# towelwise.github.io

The website for [Towelwise AI](https://github.com/towelwise/towelwise), served at https://towelwise.github.io by GitHub Pages.

It is one static page, `index.html`, with its icons in `assets/`. There is no build step: edit the file and open it in a browser. Changes go through pull requests on a `site/...` branch, like the main repo ([contributing guide](https://github.com/towelwise/towelwise/blob/main/CONTRIBUTING.md)).
